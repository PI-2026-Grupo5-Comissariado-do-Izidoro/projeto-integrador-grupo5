## Objetivo

Desenvolver uma plataforma digital interativa que promova o conhecimento sobre direitos humanos, utilizando tecnologias web para sensibilizar a comunidade e fomentar uma sociedade mais justa e equilibrada.

## Funcionalidades Principais

- **Suporte Bilíngue:** A plataforma possui versões completas das páginas em Português (PT-BR) e Inglês (EN), com navegação interligada.
- **Modo Escuro (Dark Mode):** Sistema de alternância de tema (claro/escuro) utilizando variáveis CSS e JavaScript, com preferência do usuário salva no navegador via localStorage.
- **Layout Responsivo:** Estrutura adaptável para diversos tamanhos de tela (dispositivos móveis, tablets e desktops).
- **Galeria Interativa:** Carrossel de imagens na página inicial com rolagem nativa.

## Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias padrão da web, sem a dependência de frameworks externos, garantindo leveza e alta performance:

- **HTML5:** Semântico
- **CSS3:** Variáveis CSS para temas, Flexbox e CSS Grid para layout
- **JavaScript:** Vanilla JS para manipulação da DOM e lógica de temas

## Temas Contemporâneos Transversais (TCTs)

Como base do projeto integrador, a plataforma aborda ativamente os seguintes TCTs através das pesquisas e documentações dos integrantes:

- Educação em Direitos Humanos
- Cidadania e Civismo
- Diversidade Cultural
